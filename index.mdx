  ## How the platform fits together

  ```
  WordPress site                 Studio Cloud                  App stores
  ──────────────                 ────────────                  ──────────
  BuddyBoss + Plugin ──────────► Configure app ─────────────► iOS + Android
  (data, auth,        sync        Build binary   publish        (users)
   push, IAP)                     OTA updates ───────────────► (live updates)
  ```

  | Component            | Role                                                                             |
  | -------------------- | -------------------------------------------------------------------------------- |
  | **WordPress Plugin** | Your site's data and auth layer. Connects to Studio via REST API.                |
  | **Studio Cloud**     | Control plane. Owns builds, OTA jobs, credentials, and edge config delivery.     |
  | **Mobile App**       | White-label React Native app on iOS and Android, powered by your site.           |
  | **SDK**              | Optional. For custom themes and screens built with `@blocklienterprise/runtime`. |
