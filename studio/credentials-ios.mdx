Studio needs two things from your Apple Developer account: an **App Store Connect API key** (builds, signing, and bundle identifiers) and an **APNs auth key** (push notifications).

In Studio, go to **Store Setup → Credentials → iOS**.

## 1. Connect with an App Store Connect API key

This key lets Studio sign your builds, submit to the App Store, and list or create your bundle identifiers.

### Get the details from Apple

1. Open [Apple Developer](https://developer.apple.com/account) and note your **Team ID** under **Membership details**.
1. Open [App Store Connect](https://appstoreconnect.apple.com) and go to **Users and Access → Integrations → App Store Connect API**.
2. Make sure you are on the **Team Keys** tab. Individual keys don't work with Studio.
3. Copy the **Issuer ID** shown at the top of the page.
4. Click **\+** to create a key. Name it (for example "Blockli Build") and set the role to **Admin**.
5. Copy the **Key ID** shown next to the new key.
7. Click **Download API Key**. This downloads a `.p8` file. **Apple only lets you download it once**, so keep it safe.

### Add them to Studio

| Field | Value |
| --- | --- |
| **Apple Team ID** | Your 10-character Team ID |
| **Issuer ID** | The UUID shown at the top of the App Store Connect API page |
| **Key ID** | The 10-character key ID |
| **API key (.p8)** | Upload the downloaded `.p8` file |

Click **Save & verify**. Studio checks the key with Apple and shows:

- **✓ Connected to Apple — N bundle IDs found** when everything matches.
- An error if the Issuer ID, Key ID and `.p8` don't belong together, or if the key isn't a Team key.

<Note>
  The `.p8` field is upload-only. If you lose the file, generate a new key in App Store Connect.
</Note>

## 2. Add an APNs auth key (push notifications)

After you connect, the **Push** section appears on the iOS card.

### Get the key from Apple

1. Open [Apple Developer](https://developer.apple.com/account) and go to **Certificates, Identifiers & Profiles → Keys**.
2. Click **\+**, name the key (for example "Blockli APNs"), and check **Apple Push Notifications service (APNs)**.
3. Click **Continue**, then **Register**.
4. Copy the **Key ID**.
5. Click **Download**. This downloads a `.p8` file. **You can only download it once.**

<Note>
  One APNs key works for every app in the same Apple Developer account, so you can reuse it across Blockli apps.
</Note>

### Add it to Studio

| Field | Value |
| --- | --- |
| **APNs key ID** | The 10-character key ID |
| **APNs auth key (.p8)** | Upload the downloaded `.p8` file |

Click **Save push key**.

## 3. Set your bundle identifiers

Bundle identifiers are set on the **Blockli project** tab, in the **iOS** section. You need a **release** identifier and a **test** identifier.

### Use an identifier that already exists

Open **Release bundle identifier** or **Test bundle identifier**. Studio lists the identifiers registered in your Apple account. Type to search, then pick one.

### Create new identifiers

1. Open either iOS field and choose **Register new…**.
2. In the side panel, enter a **Name** and your **Release identifier** (for example `com.yourcompany.yourapp`).
3. Studio suggests the **Test identifier** by adding `.test` to the release identifier. You can edit it.
4. Review the preview, then click **Create in Apple Developer**.

Studio creates both identifiers and fills in both fields. Identifiers that already exist are reused, not duplicated.

Click **Save** at the bottom of the tab when you're done.

<Note>
  You don't need to register identifiers in the Apple Developer portal or set up certificates and provisioning profiles yourself. Blockli creates and manages them, and enables the capabilities your app needs, when it builds.
</Note>
