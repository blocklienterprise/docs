Most of what your app displays — navigation, content, app pages, theme, modules — is delivered live from the Blockli runtime. These update automatically with no release of any kind.

An On-Air Release is different: it pushes an updated **JS bundle** directly to your users' installed apps. Use it when you've made code changes to the app that don't involve native platform changes.

This covers the vast majority of app updates — roughly 95% of what you'll ever ship.

## When to use an On-Air Release

Use it whenever you've changed app code but haven't modified the underlying iOS or Android project — for example:

- Bug fixes and UI tweaks
- New screens or flows built in JavaScript
- Logic or behaviour changes

## When a full build is required

A full build is needed when changes touch the native platform layer — for example, adding a package that modifies the iOS or Android project itself (like a new native module or SDK integration).

## How to publish

Go to **Build → On-Air Release** in Studio and trigger the release. The updated bundle is delivered to your users on their next app launch.
