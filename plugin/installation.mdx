## Requirements

| Requirement | Minimum version |
| --- | --- |
| WordPress | 5.8 |
| PHP | 7.4 |
| BuddyBoss Platform | Latest stable |

The plugin also integrates with optional plugins when they are active:

- **BuddyBoss Platform Pro** — messaging and document features
- **LearnDash** — Courses module
- **Easy Digital Downloads** — Shop/Products module
- **WooCommerce** — Shop module
- **Mux** — Livestream module

## Installation

1. Download `blockli-mobile-app.zip` from your Studio account.
2. In your WordPress admin, go to **Plugins → Add New → Upload Plugin**.
3. Choose the zip file and click **Install Now**.
4. Click **Activate Plugin**.

Once activated, a **Blockli Mobile App** menu appears in your WordPress admin. From there you can connect to Studio and configure the plugin.

## Updates

Updates are delivered through your Studio account. Download the latest zip and follow the same installation steps — WordPress will detect the existing plugin and replace it without affecting your settings.
