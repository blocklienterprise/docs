## Build 4 <span style={{color: '#9ca3af', fontWeight: 400, fontSize: '0.875rem'}}>September 29, 2026</span>

### Chat
- Edit and delete your own messages
- React to messages with emoji (SDK-backed picker)
- Forward messages, including from received threads
- Groups tab added to the Chats screen
- Multiple pinned messages per thread
- Chat message list now uses inverted scroll
- Failed message retry
- Search in chat screen

### Profiles
- Member profile redesign with refined card layout
- More-actions sheet wired to BuddyBoss member actions (follow, connect, message)
- Chat button added to member actions
- Fix: profile points showing correctly for viewed members
- Fix: header variant appearing on wrong screens

### Screens & Blocks
- Progress Map block live (reads Roadmap API, maps colors)
- Custom HTML block rendered in a WebView
- App page links and HTML block taps routed through deep-link parser
- Paywall deep links routed correctly
- WebView back navigation fixed (back button traverses WebView history first)
- Skeleton loaders for courses and lesson details
- Locked lesson handling and web chrome

### Custom Fonts
- Theme font loading from Studio configuration
- Font aliases and runtime bootstrap

### Auth & Forms
- Form field placeholder, icon, and focus colors configurable from Identity & Branding
- Field style overrides scoped to Auth screens only

### In-App Purchases
- Native iOS prices shown in purchase CTA
- Purchase confirmation loading state
- Unified entitlement handling across stores
- Stripe subscription management flow
- IAP fetches limited to visible paywalls
- Android back behavior fixed in Stripe checkout
- Active subscription state handled after checkout

### Other
- Tenant splash background support
- Multi-attachment posting in composer
- Runtime cache hydrated before app providers
- OTA debug overlay removed; redirect fixes
