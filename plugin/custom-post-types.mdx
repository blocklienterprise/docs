Blockli can surface any registered WordPress custom post type in your app as a list screen, a detail screen, or an embedded block on an App Page.

## Register a CPT as a source

1. In your WordPress admin, go to **Blockli → CPT Sources**.
2. Click **Add Source**.
3. Select the post type from the dropdown — only publicly queryable post types are listed.
4. Configure the source:
   - **Label** — the display name shown in the app
   - **Fields** — which fields to include
   - **Filter** — optional filter to limit which posts appear
   - **Order** — sort order for the list
5. Save.

## Use CPT data in the app

### Embedded in an App Page

Add a **CPT Cards** or **CPT Directory** block to any App Page in the block editor. Point the block at your registered source and it will display the content inline on that page.

### As a full list or detail screen

Once a CPT source is registered, Studio can wire it up as a standalone list or detail screen in your app's navigation. Tapping an item in the list automatically opens a detail screen that renders the fields you configured in the plugin — no coding required.
