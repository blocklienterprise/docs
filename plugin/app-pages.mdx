App Pages are custom screens you build in WordPress using the block editor. They appear in the app as full-screen content pages, accessible from the tab bar or the More menu.

## Creating an App Page

1. In WordPress admin, go to **Blockli → App Pages**.
2. Click **Add New**.
3. Give the page a title — this is the label members see in navigation.
4. Use the block editor to compose the page using Blockli blocks.
5. Publish the page.
6. In Studio, go to **App Config → Navigation** and add the page to your tab bar or More menu.

Changes to App Pages go live immediately — no app build required.

## Available blocks

| Block | Description |
| --- | --- |
| **Activity Feed** | Live activity feed from BuddyBoss or FluentCommunity. |
| **Groups** | List of community groups or spaces. |
| **Members** | List or grid of community members. |
| **Forums** | BuddyBoss forums. Tapping a forum opens its discussion topics. |
| **Notifications** | The signed-in member's notifications. |
| **Profile Card** | The signed-in member's profile details. |
| **Blog Posts** | Recent WordPress blog posts. |
| **Courses** | LearnDash courses. |
| **Quick Links** | A configurable grid of icon shortcuts linking to URLs or app screens. |
| **Featured Cards** | A curated set of featured content cards. |
| **Post Cards** | A set of post content cards. |
| **Graphic Cards** | A set of graphic content cards. |
| **Video Cards** | A set of video content cards. |
| **CPT Cards** | A horizontal card row sourced from a custom post type. |
| **CPT Directory** | A vertical and horizontal, tappable list from a custom post type. |
| **Podcasts** | Podcast episodes from your podcast plugin. |
| **Podcast Episodes** | Podcast episodes from the Blockli Podcast plugin. |
| **Podcast Authors** | Podcast authors from the Blockli Podcast plugin. |
| **Streamer** | Blockli Streamer content — videos, collections, or creators. |
| **Streamer Collections** | Blockli Streamer collections. |
| **Streamer Videos** | Blockli Streamer videos. |

## Navigation

To add an App Page to your app navigation, go to **Studio → App Config → Navigation** and add the page to the tab bar or More menu.
