Studio builds your iOS and Android app binaries in the cloud. You don't need a local build environment — everything runs remotely.

## Before your first build

1. iOS and Android [credentials](/studio/credentials-ios) must be uploaded
2. Your WordPress site must be [connected](/studio/wordpress-connection)

## Triggering a build

1. In Studio, go to **Build**.
2. Click **New Build**.
3. Select platform: **iOS**, **Android**, or **Both**.
4. Click **Start Build**.

The build typically takes **10–20 minutes** depending on queue time and platform.

## Build status

Studio shows live build status in the Build tab:

| Status | Meaning |
| --- | --- |
| Queued | Waiting for a build worker |
| Building | Build is in progress |
| Finished | Build succeeded; binary ready to download or submit |
| Failed | Build failed; check logs for errors |

Click any build row to see the full build log.

## Development builds

In addition to production builds, Studio can create **development builds** — binaries that include a dev client for live preview sessions.

- One active development build is allowed per platform per app
- Development builds use a special bundle identifier suffix to avoid conflicting with production
- Once a dev build is installed, Studio can start a **preview session** (a Metro server) so you can test configuration changes live on device

See [Development Previews](/studio/development-previews) for the full workflow.

## Build credits

Builds consume credits from your Studio account. 

Credit balance is shown in **Account → Credits**.

## After the build

When a production build finishes you have two options:

- **Publish from Studio** — submit directly to the App Store or Google Play without leaving Studio (see [Store Submission](/studio/store-submission))
- **Download and upload manually** — download the `.ipa` (iOS) or `.aab` (Android) from Studio and upload it yourself in App Store Connect or the Google Play Console
