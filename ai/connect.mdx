Agents connect to your WordPress site's MCP server. You'll find its address in **Blockli → Tools → AI Tools**. It looks like this:

```text
https://your-site.com/wp-json/blockli/mcp
```

There are two ways to sign in:

- **Cursor, Claude Code, and Claude Desktop** sign in with a WordPress **application password**.
- **ChatGPT and Claude.ai** sign in through your site: they open a page where you sign in to WordPress and click **Allow**. No password to copy.

## Before you start

- You're an administrator on the WordPress site.
- **Allow AI agents to use the Blockli tools** is switched on in **Blockli → Tools → AI Tools**.
- For ChatGPT and Claude.ai, your site uses **https**. Their servers can't reach a site on plain http.

## Connect with an application password

<Steps>
  <Step title="Create an application password">
    In **Blockli → Tools → AI Tools**, follow the **Create one in your profile** link. Name the password after the agent, for example `Cursor`, and copy it.
  </Step>
  <Step title="Paste it on the AI Tools page">
    Paste it into **Application password** on the same page. The page fills in the setup for your agent. The password isn't saved there; it only builds the setup text.
  </Step>
  <Step title="Add the setup to your agent">
    Pick your agent's tab and copy the setup.
  </Step>
</Steps>

<Tabs>
  <Tab title="Cursor">
    1. Open `.cursor/mcp.json` in your project, or `~/.cursor/mcp.json` to use it in every project.
    2. Paste the copied `"blockli-app"` entry inside `"mcpServers"`, next to any servers already there. Add a comma after the server before it.
    3. If the file is empty, wrap it like this:

    ```json
    {
      "mcpServers": {
        "blockli-app": {
          "url": "https://your-site.com/wp-json/blockli/mcp",
          "headers": { "Authorization": "Basic …" }
        }
      }
    }
    ```

    4. Save, then switch **blockli-app** on in Cursor's MCP settings.
  </Tab>
  <Tab title="Claude Code">
    Run the copied command in a terminal. It adds Blockli next to any servers you already have:

    ```bash
    claude mcp add --transport http blockli-app https://your-site.com/wp-json/blockli/mcp --header "Authorization: Basic …"
    ```
  </Tab>
  <Tab title="Claude Desktop">
    1. Open **Settings → Developer → Edit Config** to open `claude_desktop_config.json`.
    2. Paste the copied `"blockli-app"` entry inside `"mcpServers"`.
    3. Restart Claude Desktop. This setup needs Node.js installed.
  </Tab>
</Tabs>

<Warning>
  The setup contains your application password. Don't share it or commit it to a repository. To disconnect an agent, revoke its application password in your WordPress profile.
</Warning>

## Connect ChatGPT or Claude.ai

<Tabs>
  <Tab title="Claude.ai">
    1. On claude.ai, open **Settings → Connectors** and click **Add custom connector**.
    2. Name it `Blockli App` and paste your MCP server address as the **Remote MCP server URL**.
    3. Leave the OAuth client ID and secret empty. Your site registers Claude by itself.
    4. Click **Add**, then **Connect**.
    5. Claude opens your site. Sign in to WordPress if asked, check the details, and click **Allow**.
    6. In a new chat, switch **Blockli App** on in the chat's tools menu.

    <Note>
      Custom connectors may need a paid Claude plan. On Team and Enterprise plans, an Owner may need to add the connector for the organization.
    </Note>
  </Tab>
  <Tab title="ChatGPT">
    1. In ChatGPT, open the settings for apps and connectors and create a custom MCP connector. You may need to turn on developer mode first.
    2. Name it `Blockli App` and paste your MCP server address as the server URL.
    3. Choose **OAuth** for authentication. Leave the client details empty; ChatGPT registers itself with your site.
    4. Confirm the warning about custom servers and create the connector.
    5. ChatGPT opens your site. Sign in to WordPress if asked, check the details, and click **Allow**.
  </Tab>
</Tabs>

The **Allow** page shows which app is asking, your site, and the account it will act as. Only administrators can allow a connection.

### Connected apps

Apps that signed in this way appear under **Connected apps** in **Blockli → Tools → AI Tools**, with the account they use and when they were last used. Click **Disconnect** to sign one out; it has to ask you to **Allow** again before it can use the tools.

Access lasts while the app keeps using it, up to 30 days without use. The sign-in only works for the AI tools, nowhere else on your site.

## Verify

Ask your agent:

```text
Call get-started and tell me in plain words: what my site and app have,
which supporting plugins are active, how many app pages there are,
and which tools you can use right now.
```

It should describe your site, your app pages, and the active plugins.

## Troubleshooting

| What you see | Likely cause | What to do |
| --- | --- | --- |
| "The Blockli AI tools are turned off" | The main switch is off. | Turn on **Allow AI agents to use the Blockli tools** in **Blockli → Tools → AI Tools**. |
| "Only site admins can use the Blockli AI tools" | The account isn't an administrator. | Use an administrator's application password, or sign in as an administrator on the **Allow** page. |
| Cursor shows "An unexpected error occurred" | The agent has an old copy of the tool list. | Switch **blockli-app** off and on in Cursor's MCP settings, then try again. |
| New tools don't appear after a plugin update | The agent cached the old tool list. | Turn the server off and on in your agent, or restart it. |
| ChatGPT or Claude.ai can't connect | The site isn't on https, or a security plugin blocks the sign-in pages. | Use https. Make sure `/wp-json/blockli/oauth/` and `/.well-known/oauth-authorization-server` are reachable. |
| "Application passwords are turned off" on the AI Tools page | The site isn't on https, or a security plugin disables them. | Use https, or allow application passwords in your security plugin. |

If it still doesn't work, contact support.
