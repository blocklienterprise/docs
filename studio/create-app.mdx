There are two ways to get started — create the app in Studio first, or let the WordPress plugin create it for you during the connect flow. Both end up in the same place.

## Option 1: Create in Studio first, then connect from WordPress

### Create the app

1. Log in to Studio and click **New App** (or **Create App** on an empty account).
2. Enter your **App Name** — the display name for your app (e.g. "My Community").
3. Click **Create**.

Studio creates the app record and assigns a unique `appId`.

### Connect your WordPress site

1. In your WordPress admin, go to the **Blockli Mobile App** plugin and open **Overview**.
2. Click **Connect**. You'll be redirected to Studio automatically.
3. Studio shows your list of apps. Select the app you just created.
4. The connection is confirmed and your WordPress URL is set up automatically.

## Option 2: Connect from WordPress and create the app there

If you haven't created an app in Studio yet, you can do it directly from the WordPress connect flow.

1. In your WordPress admin, go to the **Blockli Mobile App** plugin and open **Overview**.
2. Click **Connect**. You'll be redirected to Studio.
3. Instead of selecting an existing app, choose to create a new one and enter your app name.
4. Complete the creation and the connection is set up in one step.

## Managing multiple apps

You can create multiple app records under one Studio account. Common scenarios:

- **Multiple tenants** — different community sites, each with their own app
- **Development vs. production** — separate app records with different bundle IDs for testing builds

Each app record has completely independent credentials, build history, and configuration.
