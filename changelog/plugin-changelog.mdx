## 1.1.14 <span style={{color:'#6b7280',fontWeight:'normal',fontSize:'0.875rem',marginLeft:'0.5rem'}}>2026-10-23</span>

### Added

- Blog Posts block options: category and tag filters, featured images, post details, author avatars, comments and bookmarks. Existing category filters carry over automatically.
- App sign-ins renew themselves: members who keep using the app stay signed in.
- Changing a password signs out every app sign-in made before the change. A change made from the app keeps that device signed in.
- The app is told why a sign-in was refused, so it can handle expired or invalid sign-ins gracefully.

### Changed

- App sign-ins now last 90 days without the app being opened (previously 7 days, never renewed).
- Post filters and author details work the same way for blog posts and custom post types.

### Fixed

- BuddyBoss App Posts blocks now convert correctly during migration.

## 1.1.0 <span style={{color:'#6b7280',fontWeight:'normal',fontSize:'0.875rem',marginLeft:'0.5rem'}}>2026-10-22</span>

### Added

- [AI App Builder](/ai/overview): set up app pages and blocks, menus, settings, content, access, purchases and your BuddyBoss App migration by chatting with an AI assistant, with secure admin sign-in.
- Push notifications from WordPress: preview, send, schedule, edit scheduled pushes, and see history.
- GIF search in the app, using your site's BuddyBoss GIPHY key.

### Changed

- Access control now supports default rules, category rules, more plugin conditions, and BuddyBoss-compatible precedence.
- Better block editor previews, content source search, carousel excerpts, and undo for each change.

### Fixed

- Access rules are enforced everywhere the app reads content, including navigation and media.
- The BuddyBoss Theme footer is hidden on pages the app opens in a web view.
- Migration and editor edge cases involving unavailable blocks, private previews, media lists and video timing.

## 1.0.9 <span style={{color:'#6b7280',fontWeight:'normal',fontSize:'0.875rem',marginLeft:'0.5rem'}}>2026-09-27</span>

- Course gating now follows access rules, and unnecessary header spacing is hidden.

## 1.0.0 <span style={{color:'#6b7280',fontWeight:'normal',fontSize:'0.875rem',marginLeft:'0.5rem'}}>2026-08-25</span>

Initial release.

### Added

- WordPress token authentication for the mobile app, social login, and one-time WebView session handoff URLs.
- Integrations for BuddyBoss Platform, BuddyPress, bbPress, FluentCommunity, WooCommerce, LearnDash, podcasts, and Blockli Streamer.
- Blockli Studio connection, multi-tenant cloud config, and feature flags.
- App Pages with native blocks, legacy card migration, CPT sources, and a CPT screen layout builder.
- Versioned mobile navigation (tab bar, more menu, header bar) with an icon picker and multi-locale labels.
- Push notifications with deep links, per-type preferences, targeted test pushes, and device observability.
- Realtime bridge for messages, notifications, activity, groups, forums, friendships, and profile updates.
- Bunny Edge caching with scoped cache invalidation.
- Access control with audiences, paywalls, and content gates.
- In-app purchases (Apple, Google Play, Stripe web checkout) with access grants.
- React admin SPA with light/dark mode.
