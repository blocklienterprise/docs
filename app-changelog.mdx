## Build 4 <span style={{color:'#6b7280',fontWeight:'normal',fontSize:'0.875rem',marginLeft:'0.5rem'}}>2026-09-29</span>

### Added

- Chat: message edit and delete, pin/unpin with real-time broadcasts, message reactions, forwarding, emoji picker, groups tab, and skeleton loaders.
- Multiple pinned messages per chat thread, with cycling between them.
- Progress Map block in the app page editor.
- Custom font support — theme fonts load at runtime and apply across the app.
- Configurable form field styling: placeholder text, icon, and focus colors from Identity & Branding settings.
- Native iOS in-app purchase flow with store prices shown in purchase CTA buttons.
- Multi-attachment posting in the composer.
- Tenant splash background support.

### Fixed

- Images not loading in posts and content.
- Custom HTML blocks not rendering — now displayed in a sandboxed WebView with correct script and CORS handling.
- More-menu web links not opening.
- GamiPress wrong points shown on other member profiles.
- Full reload on every app reopen — content is now cached on launch.
- No message button on member profiles.
- App header appearing on screens other than the activity feed.
- Dark mode display bugs in profile, chat, and post-creation screens.
- WebView back navigation leaving the screen instead of going back within the page.
- Missing sender name on own chat messages.
- LearnDash locked lesson handling and web chrome visibility.

## Build 2 <span style={{color:'#6b7280',fontWeight:'normal',fontSize:'0.875rem',marginLeft:'0.5rem'}}>2026-09-14</span>

### Added

- Chat: new-chat screen, loading skeletons, optimistic message send, thread actions, iOS rich push extension, and inverted message list.
- Profile card block.
- Profile points and achievements redesigned into separate sections, capped at three cards.
- OTP email verification on sign-up.
- Login screen redesign.
- Forum: discussion action sheet, pinned discussion highlighting, and topic actions.
- Forum and group block filtering.
- YouTube link previews in activity feeds.
- Page view tracking and stable hardware device IDs.

### Changed

- Joined date and bio hidden from profile view.
- Chat list and tab pagination with lazy-loaded unread badges.
- Tab bar labels and terms text fixed on narrow screens.

### Fixed

- Push notification delivery.
- Chat keyboard spacing on Android.
- Chat avatar fallback in details view.
- Stale follow/connect state in member action sheet.
- Header logo dimensions mapped from config values.
- Exercise guide in-app bug reports; multiday and single-day workout flow bugs.
